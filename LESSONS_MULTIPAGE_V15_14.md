# SCOUT HUB V15.14 — Lessons multi-page

Les leçons peuvent maintenant être affichées en plusieurs pages.

- Limite: **3000 caractères maximum par page**.
- La découpe essaie de respecter les paragraphes et les phrases.
- Navigation: Précédent / Suivant.
- Indicateur de progression: page actuelle / nombre total.
- Le bouton final peut déclencher `onComplete()` pour valider la leçon.
- Le module ne remplace pas les données existantes: il fournit une couche de pagination réutilisable.
